# 开发计划与当前限制

本文件收纳尚未完成的功能和已知限制，不代表已经实现，也不承诺交付日期。
当前能力基线见 [开发指南](development.md)，操作见 [使用说明](user_guide.md)。

## 尚未完成

- PSD 分层解析、图层映射、重新导入与解析依赖打包；当前可使用分层 PNG。
- 配饰二级物理、骨链、IK、物理烘焙与 Live2D SDK。
- 动画对比、参考图面板、图片序列批量导入、不等帧时长、时间轴重排和逐帧层级、枢轴编辑。
- 战斗属性、技能、特效、弹体轨迹、多角色操控与追逐 AI。
- 创作应用内地图编辑、后台全局快捷键、整窗点击穿透、完整多屏与真实系统 DPI 适配。
- 单文件桌宠、自动安装运行插件、旧格式迁移、打包归档导入与模块热加载。
- 原型能力的完整承接与其余产品规划。

## 当前限制

- 地图在 `runtime/game/world.tscn` 中由 Godot 编辑；创作应用没有完整关卡编辑器。
- 游戏试演包含移动、碰撞与动作，不执行战斗技能。
- 桌宠按轮廓凸包处理点击穿透，凹洞不进行逐像素穿透。
- 更高且不兼容的工程格式版本会被拒绝，不会自动降级或删除字段。
- 跨物理电脑、多显示器、真实系统 DPI、下层应用穿透与长时间运行仍需实际验收；
  已执行的验证及证据见 [验收记录](validation.md)。
