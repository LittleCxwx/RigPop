# RigPop 0.1.2 Windows Demo

面向像素角色的动画与桌宠创作工具，当前为功能尚在完善的 Demo 预览版。

## 0.1.2 更新

- 三头身 OC 底模拆分头、表情、躯干和各段四肢，可独立绘制或换图。附带可选的服装、发型、围巾和尾巴。
- 支持 PSD 分层导入、原画位置保留、骨骼匹配与动作预设。可编辑工程可随附原 PSD。
- 桌宠支持普通、聚焦和固定三种模式。普通模式中按住 WASD 可移动桌宠，同时前台应用照常接收按键。固定模式锁住位置和倍率，并通过屏幕左下角图标打开菜单。
- 新增「桌宠试演 → 状态与动作」。可设置持续表情、坐姿、移动或跳跃限制和特定状态的动作替换。默认坐下状态禁止移动和跳跃。一次性动作播完后恢复当前状态。
- 桌宠从托盘控制显隐，切换模式时保持主任务栏空闲。点击菜单外部即可收起菜单。

## 下载和启动

1. 在本页 **Assets** 中下载 `RigPop-0.1.2-win64.zip`。
2. 将整个压缩包解压到一个可写文件夹。
3. 双击其中的 `RigPop.exe`，无需安装 Godot、Python 或下载源码。

请保留整个解压目录，包括 `RigPop.pck`、`rigpop_windows.dll`、`platform/`、`hosts/`、`helpers/` 和许可证。
页面自动附带的 `Source code` 是开发源码，不是可直接使用的程序。

适用 Windows 10/11 x64，显卡驱动需支持 OpenGL 3.3。当前没有代码签名，首次启动可能出现
Windows 发布者提示。

角色工程默认保存到程序旁 `portable_data/`。更新版本或迁移电脑时，请保留并迁移这个目录，
以及通过“另存为”保存在其他位置的角色工程；PNG 素材必须与 JSON 一起搬移。

发布包包含编辑器、桌宠运行宿主、资源和第三方许可证；不含用户作品、测试输出或导出模板。
`SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。

## 当前范围

支持角色与部件编辑、基础像素绘制、动作关键帧、图片/图集导入、游戏试演、桌宠试演、
可编辑工程保存、Godot 角色包与桌宠目录包导出。

PSD 重导入合并、二级物理、战斗能力与完整多屏适配仍在开发。完整范围和验证边界见仓库
`docs/roadmap.md` 及 `docs/validation.md`。
