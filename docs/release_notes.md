# RigPop Windows Demo

面向像素角色的动画与桌宠创作工具，当前为功能尚在完善的 Demo 预览版。

## 下载和启动

1. 在本页 **Assets** 中下载 `RigPop-<版本>-win64.zip`。
2. 将整个压缩包解压到一个可写文件夹。
3. 双击其中的 `RigPop.exe`，无需安装 Godot、Python 或下载源码。

请保留 `RigPop.pck`、`hosts/` 和许可证文件。不要只复制 EXE，也不要在 ZIP 内直接运行。
页面自动附带的 `Source code` 是开发源码，不是可直接使用的程序。

适用 Windows 10/11 x64，显卡驱动需支持 OpenGL 3.3。当前没有代码签名，首次启动可能出现
Windows 发布者提示。

角色工程默认保存到程序旁 `portable_data/`。更新版本或迁移电脑时，请保留并迁移这个目录，
以及通过“另存为”保存在其他位置的角色工程；PNG 素材必须与 JSON 一起搬移。

发布包包含编辑器、桌宠运行宿主、资源和第三方许可证；不含用户作品、测试输出或导出模板。
`SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。

## 当前范围

支持角色与部件编辑、基础像素绘制、动作关键帧、图片/图集导入、游戏试演、桌宠试演、
可编辑工程保存、Godot 角色包与桌宠目录包导出。

PSD、二级物理、战斗能力、完整多屏与真实系统 DPI 适配等仍未完成。完整范围和验证边界见仓库
`docs/roadmap.md` 及 `docs/validation.md`。
