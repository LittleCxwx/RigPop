# RigPop 0.1.2 使用说明

双击 `RigPop.exe` 进入角色工作区。请保留同目录 `RigPop.pck`、`rigpop_windows.dll`、`platform/`、`hosts/`、`helpers/` 与 `licenses/`。
无需安装 Godot 或 Python。最低工作区尺寸为 960×640，推荐 1280×800 或更大。

## 创建与保存

- 首次打开默认显示“三头身 OC 底模”。也可从左侧“新建”选择底模、Kiki、蓝衣冒险家、灵犀、人形基础、果冻团子和空白结构，或导入 PSD。“复制”建立独立角色副本。
- 左侧角色库列出便携目录中的角色与最近打开的工程；下次启动会重新打开最后保存的角色。
- 顶部“保存”或 Ctrl+S 保存；Ctrl+Shift+S 选择另存目录。
- 默认工程保存在程序旁 `portable_data/<角色ID>/`。目录不可写会报错，不会自动切换位置。
- 外部工程从“打开”选择 `character.rigpop.json`，PNG 素材必须随工程一起搬移。
- 替换角色或关闭程序时，未保存修改需要确认。Ctrl+Z 撤销，Ctrl+Y 重做。
- 每次保存保留上一版 `character.rigpop.json.bak`；恢复时可在独立目录中将备份改名后打开。

## 部件与动作

左侧树选择部件，右侧修改名称、父节点、位置、旋转、枢轴、遮挡层级与可见性。
三头身底模将头、表情、躯干、双侧上臂、前臂、手、大腿、小腿和脚分开。点部件旁的眼睛可显示预设的发型、上衣、围巾和尾巴。
选择一个部件后，可以到“像素绘制”修改原图，或用右侧“替换部件图片”换成自己的素材。保持原图尺寸和关节在图内的位置，可直接沿用现有动作。
点击画布中的不透明像素也可选中部件，拖动移动部件；中键平移，滚轮缩放。
工具栏的适合画布、骨骼、洋葱皮与镜像只改变预览。

底部选择动作与帧。播放、回到首帧、倍率、新增、复制与删除动作均在时间轴工具栏。
右侧动作属性位于部件属性下方，可滚动查看，包含名称、长度、帧率、循环、叠加和冲突设置。
在帧号或轨道空白处按住左键拖动可连续选帧。拖动关键帧菱形可移动该帧；目标已有关键帧
时交换两帧，保留各自的位置、旋转和换图。一次拖动可整体撤销。

“关键帧”开关关闭时，修改绑定姿势；开启后，位置、旋转与拖动写入当前帧。
旁边菱形按钮插入当前部件关键帧，右侧可删除当前关键帧。采样采用逐帧保持。
叠加动作只覆盖有关键帧的部件，例如旅人的招手只覆盖右手，不改变行走中的腿部。
多个叠加动作作用的部件互不冲突时可同时播放，例如移动、招手与头部动作。
父关节动作会影响子关节和挂接部件，这些也计入冲突范围。全身动作占用全部部件。

冲突时，“替换低 / 同优先级动作”允许新动作替换优先级不高于自己的冲突动作；较高优先级
动作继续播放。“放弃本次动作”则在存在冲突时不启动新动作。不冲突的动作继续各自播放。
“播放时禁止移动”可用于蓄力等动作；动作结束后，仍按住的方向键会继续移动。
按键触发的动作播放一次后返回移动或待机；编辑器连续播放使用动作的循环设置。

## 多关节绑定

左侧部件标题旁的骨骼图标添加关节，选中关节后右侧“添加子关节”可建立上臂、前臂、手
等逐级结构。通过“父节点”将图片部件挂到相应关节；换父节点时保留绑定姿势中的世界位置。
父关节旋转时，子关节和部件随之转动。关节可重命名、拖动、旋转，也可记录位置和角度关键帧。
打开画布骨骼显示后，圆环是可选取的关节手柄。删除中间关节会将其子节点挂到上一层，
保留绑定姿势；可撤销恢复。

这是适合像素部件的刚性 FK 关节链，不包含网格权重、软变形或 IK。每帧仍可独立换图和
手绘修正；旋转效果不满意时，直接绘制该帧的手臂、剑或整个人物，无需依赖骨骼变形。

## 像素与导入

“像素绘制”编辑选中部件：铅笔、橡皮、填充、取色、完整调色和自定义色板。
滚轮调整整数倍率，中键平移。一个连续笔画作为一次撤销操作。

默认选择“当前帧”：第一次落笔时自动为所选帧建立独立图片，前后帧、基础图片及其他动作
保持原样；后续笔画复用该帧的图片。切换到“共用图片”则明确编辑所有引用该图的帧。
像素绘制范围与底部控制位置、旋转的“关键帧”开关分别设置。

“复制上一帧图片”将上一帧的画面复制到当前帧，之后可独立修改；“新建空白帧”从透明图片
开始；“导入当前帧图片”可替换成完全不同的 PNG、JPG 或 WebP，不要求轮廓、尺寸相同。
“当前帧独立换图”可在绘制前显式复制当前显示的图片。以上操作均支持撤销、重做与保存。

例如绘制挥剑动作：在时间轴选择“挥砍”动作和下一帧，复制上一帧或导入新的挥剑图片，
再用铅笔、橡皮和填充重画手臂、剑身及拖影，逐帧完成准备、挥出、命中和收招。
部件动作只需替换相关部件；整个人物轮廓都改变时，可在空白角色中将整张人物图作为一个
部件导入，再逐帧替换整图。待机、挥砍等不同动作各有自己的帧序列，不受部件旋转的限制。

透明裁边在“共用图片”范围用于基础图片，并同步枢轴；逐帧图片暂不支持独立枢轴和透明
裁边，以免影响父子部件装配。调整尺寸可选择只改画布或最近邻重采样，“当前帧”范围只
修改本帧；重采样共用基础图片会同步缩放枢轴。为保持逐帧对齐，优先采用统一画布和锚点。

“导入图片 / 图集”支持 PNG、JPG、WebP。预览后设置行列数；图集按从左到右、从上到下
切分为一个部件的逐帧换图动作。最多 240 帧，图像尺寸必须能整除行列数。
单张图片作为新部件；替换现有部件使用右侧“替换部件图片”。
整体精灵图可在空白角色中导入。图片序列批量导入与逐帧不等时长尚未接入。

## 骨骼模板与预设

角色属性可选择“小兽”或“人形”骨架，再为部件指定标准部位。骨架使用稳定的部位标识匹配
动作，不要求部件 ID 相同。枢轴、父节点和姿势仍可自由调整；这是刚性部件动画，不含网格蒙皮。
灵犀默认包含待机、行走、奔跑、招手、点头、跳跃、坐下、睡觉、摇尾巴九个动作。
默认新角色 Kiki 使用 Tyson Tan 的专业 Q 版赛博松鼠立绘（Krita 吉祥物，CC BY-SA 4.0），
包含悬浮待机、漂浮移动、轻快漂浮、摇摆问候、歪头致意与跳跃。它保留完整原画，使用整体
位移和旋转，不含独立四肢骨骼，也不把漂浮动作当成踏步动画。导出随附作者署名及授权。
Kiki 使用平滑采样显示插画；像素角色仍使用最近邻采样。

“蓝衣冒险家”使用 Kenney CC0 Q 版美术，包含 9 个可独立编辑的部件、待机、行走、
奔跑、招手、点头、跳跃六个骨架动作，以及专注、惊讶两种换图表情。人形预设使用适合正面
短身人物的摆臂、踏步和抬手角度。后发挂在头部、手掌挂在手臂，调整父部件时一起移动。

时间轴工具栏的预设库按钮可批量添加动作。保存图标或右侧“存为骨骼预设”将当前动作存入
`portable_data/presets/`；同骨架的另一个角色可在预设库中调用。动作支持位置、旋转、可见性，
带逐帧换图的动作应通过复制角色工程复用。预设只提供初始姿势，换画后需检查枢轴和接缝。

## PSD 分层导入

从“新建 → 从 PSD 导入分层角色”选择 PSD。解析后可看合成预览，选择骨架，调整各图层的
导入勾选、可见性和部位；未分配部位的图层保留为普通部件。重复部位会提示，修正后才能确认。
导入保留中文图层名、分组信息、绘制顺序、透明度和原画位置，并生成适用的动作。导入可整体撤销。

目前支持 8 位 RGB/RGBA PSD，画布和单层不超过 4096 像素，最多 256 层，文件不超过 256 MiB。
图层栅格蒙版由解析库合成。剪贴、特殊混合、图层效果和组蒙版会在报告中提示，应先在 Photoshop
中合并或栅格化；文字、智能对象使用 PSD 保存时已有的栅格结果，不提供原生编辑。
源 PSD 随可编辑工程保存到 `sources/`；迁移工程时一并复制。Godot 与桌宠运行包只携带渲染素材。
再次导入会建立新角色，当前还不支持自动合并旧动作与重新导入后的图层。

## 游戏试演

切换到游戏试演，点击场地或右侧“操控角色”后接收键鼠输入。默认 WASD 移动、空格招手。
控制绑定先选择“键盘”或“鼠标”：键盘点击按键格后实际按键，Esc 取消捕获；鼠标从下拉框
选择左键、右键或中键。无需输入设备键名。触发方式有持续移动、点按、长按、双击。
点按的释放时间需短于
300 ms；与双击共用按键时等待 250 ms 双击窗口，长按在 300 ms 触发一次。
移动只绑定“持续移动”，动作绑定点按、长按或双击；重复的按键和手势组合会被拒绝。

右侧可修改速度与碰撞半径并复位场景。失焦与切换工作区会清理按住状态。
地图的墙、石块碰撞、出生点和相机保存在独立的 Godot 场景中，创作应用暂不提供地图编辑 UI。
当前不含战斗、技能处理器、追逐 AI 或多角色切换。

## 桌宠试演与导出

在“桌宠试演”中点击“启动独立桌宠”打开透明窗口。右键点按角色可切换模式；“停止试演”关闭由编辑器启动的窗口。

- **桌宠模式**为默认模式。按住 `WASD` 约 0.2 秒开始移动桌宠，打字时短按方向键位不会使它移动。前台应用照常接收按键。三头身底模的 `Space` 是跳跃，`H` 是开心。左键拖动角色，按住右键上下拖动可调整 1～8 倍倍率。
- **聚焦模式**让桌宠获得键盘焦点。用 `WASD` 移动桌宠时，浏览器等其他窗口不会同时收到按键。点击其他应用可临时切走焦点，点击桌宠可继续操控，按 `Esc` 切回桌宠模式。
- **固定模式**锁住角色位置和倍率。动作键仍可在后台触发，鼠标会穿过整个角色。点击所在屏幕左下角、任务栏上方的紫色 R 猫头，可切换模式、隐藏、恢复或退出桌宠。隐藏后图标仍会保留。

前两种模式的透明区域按角色轮廓的凸包穿透。桌宠不占 Windows 主任务栏按钮，前两种模式可通过系统托盘控制显隐和菜单。右键动作绑定用于游戏试演与 Godot 导出。

在「桌宠试演 → 状态与动作」中可以设置状态的切换键、姿势、动作替换以及移动和跳跃限制。列表中的第一项是启动状态。状态在按下绑定键时切换，并持续到下一次状态切换。三头身底模默认使用 `1` 原始、`2` 开心、`3` 生气、`4` 坐下。开心和生气可以一边移动一边保留表情，并各自使用专属跳跃。坐下会锁住 WASD、自由漫游和跳跃。

桌宠一次性动作播放期间会忽略其他桌宠动作、移动和状态键。动作播完后恢复当前状态，期间按下的键不排队。时长超过 5 秒的动作会在 5 秒内加速播完。运行中的桌宠会在重新启动试演后读取设置。

顶部“导出”有三种结果，选择父目录后生成独立的新目录，不覆盖用户场景：

| 结果 | 内容 |
| --- | --- |
| 可编辑工程 | `character/character.rigpop.json`、PNG 和导入时保留的 `sources/`，可重新打开 |
| Godot 角色包 | `characters/<ID>/character.tscn`、素材、共用运行源码、结构化清单与独立演示项目 |
| Windows 桌宠 | `RigPopPet.exe`、`RigPopPet.pck`、`rigpop_windows.dll`、`platform/`、`character/`，双击即可运行 |

Godot 包在 Godot 4.7.2 中打开 `project.godot` 可独立试演。合入现有项目时，只复制
`addons/rigpop_runtime/` 与 `characters/`，保持目录结构，复用同版本运行组件。
不要用演示包的 `project.godot` 或 `preview.*` 覆盖自己的工程。
可调用接口、角色入口与能力限制见导出包的 `manifest.json` 和 README。

## 当前限制

这是创作与导出闭环的 demo。PSD 重导入合并、配饰二级物理、动画对比、战斗/技能、
完整多屏/DPI 系统适配、单文件桌宠、旧格式迁移与完整原型承接属于后续工作。
动画尚未支持轨道逐帧枢轴/层级、批量时间重排、帧时长权重与高级插值。
工程只支持格式版本 1，更高版本会拒绝打开；未知模块数据保留，但不会执行其能力。
