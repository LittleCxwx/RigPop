# 开发指南

本文件记录当前实现、模块边界和开发验证。产品入口见 [英文首页](../README.md) 与
[中文首页](../README_ZH.md)，后续工作见 [开发计划](roadmap.md)。

## 开发环境

工程使用 Godot 4.7.2 stable 标准版、GDScript 与 GL Compatibility 渲染。
主场景为 `editor/main.tscn`；Windows 发布程序为 `RigPop.exe`。
源码打开、导出模板与便携包构建步骤见 [构建与发布](build_and_release.md)。

## 界面主题

色值、字阶与控件皮肤集中在 `editor/theme.gd`，图标集中在 `editor/icons.gd`。
面板只组合控件，不单独定义颜色或另加皮肤。当前约定：

- 色板从品牌标记的主紫 `#8D40BF` 派生：保留色相、把彩度压到极低，得到紫灰纸底盘
  `#F2EEF8`。这是"紫灰纸"而不是薰衣草糖果色，否则控件会互相糊在一起、输入框发灰。
- 只有一种底盘色和一档墨色文字；分区用 1 px 细线，不给控件加边框。
- 信号色只有一个暖色（赭红 `#B24A31`），与紫互补，只用于播放头、关键帧、未保存标记
  这类"当前"状态。整屏没有第二个饱和色。
- 画布保持中性深色 `#1E1C22` 而不是紫色：像素工具需要中性背景才能判色准。
- 字号四档：11 分区标题、12 说明、13 正文与控件、16 品牌；字重只分 500 与 600。
- 顶栏品牌标记使用 `assets/rigpop-mark.png`（52×48 两倍资源，运行时双线性缩到 26×24），
  不使用绘制图标。
- 页签选中态用底线而不是填充块；主操作是全屏唯一的实心墨色按钮。

## 模块与依赖

```text
core/               角色模型、动作求值、输入手势与撤销历史
services/           工程事务存取与模板素材
editor/             工作区、检查器、画布、像素工具、时间轴和编辑命令
runtime/shared/     共用角色视图
runtime/game/       地图、碰撞、输入与动作叠加
runtime/desktop/    原生透明窗口、拖动、漫游与桌面输入
exporters/          独立目录导出与明文运行模板
assets/             应用图标、中文字体与示例素材
tests/              核心、编辑器、桌宠验证与截图
tools/              模板下载、构建、源码同步与打包
docs/               使用、格式、构建、开发与验收文档
```

模型不引用界面或文件系统。工程服务负责 JSON 与 PNG，编辑器通过服务保存；
运行视图只接收角色模型与贴图。游戏与桌面适配层相互独立。
RigPop 工程不在运行时依赖外部 FlufflightDemo 目录。

角色包导出的源码来自 `exporters/templates/` 中随应用发布的明文文件，构建时从当前
运行源码同步，不依赖反向读取发布版编译脚本。修改运行组件后应重新同步模板或构建。
创作应用构建与用户角色导出属于不同流程。

## 验证

根据改动范围选择检查，完整验证记录和实际覆盖边界见 [验收记录](validation.md)。

```powershell
# 将路径替换为自己的 Godot 4.7.2 console 程序。
$godot = 'C:\Tools\Godot\Godot_v4.7.2-stable_win64_console.exe'

# 核心、编辑与导出回归。
& $godot --headless --path . --script tests/run_tests.gd

# 通过实际鼠标事件检查部件选择、添加与撤销重做。
& $godot --headless --path . --script tests/part_interaction_test.gd

# 逐帧绘制、整图换帧、存取导出及颜色弹窗对比度。
& $godot --headless --path . --script tests/pixel_frames_test.gd

# 在实际窗口运行同一套件，并生成截图。
& $godot --path . --script tests/run_tests.gd

# 对最终便携包进行独立目录成品检查。
./tools/verify_package.ps1
```

源码检查覆盖结构校验、层级循环、路径穿越、格式版本、动作保持采样、叠加轨道、
存取回读、图片身份、撤销重做、图集导入、独立帧、手势互斥、失焦、碰撞、导出与布局。
Windows 成品检查覆盖保存、重开、三种导出与导出桌宠启动。
